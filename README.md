# Aplikasi Form Profil Mahasiswa

Aplikasi Android sederhana menggunakan **Jetpack Compose** untuk memenuhi tugas pemrograman Android.

## Fitur Utama
* **State & Event Management:** Form input memperbarui data secara langsung (*real-time*).
* **Recomposition UI:** Kartu profil dan avatar inisial nama berubah otomatis saat pengguna mengetik.
* **Material Design 3:** Tampilan modern dengan kartu profil dan header gradien.
